# Deepvue Device Intelligence examples

Runnable examples for [Deepvue Device Intelligence](https://deepvue.ai): device IDs, risk verdicts
and fraud signals for web and mobile apps.

| Example | What it shows |
| --- | --- |
| [`playground/`](playground/) | A no-sign-up page that runs the web SDK on your own browser and shows the verdict, device ID and every check. |
| [`use-cases/`](use-cases/) | Fraud demos for lenders and fintechs: edited loan applications, referral cashback farming, SMS pumping and credential stuffing, each with what your backend sees and the code. |

To add Device Intelligence to your own app, get an SDK key at
[dashboard.deepvue.ai](https://dashboard.deepvue.ai/sign-up) and follow the setup guide there.
