Try to fool it

  1. Submit the application as it is.
  2. Raise the monthly income, the way someone would after a decline, and submit again.
  3. Open this page in a private window, or clear this site's data, and apply with other details. The device ID stays the same.
  4. Turn on a VPN and apply.

Press Forget this device to start over.

Why per device

A new PAN or mobile number is easy to borrow. The phone or laptop the fraudster applies from changes far less often, so it ties the attempts together.

The SDK collects device and browser metadata, never names, phone numbers or emails. The demo server keeps each device's history in memory for 24 hours.
