Try to fool it

  1. Create an account. The cashback is credited.
  2. Press New number and create another, as someone with a drawer of SIM cards would.
  3. Open this page in a private window, or clear this site's data, and sign up again. Same device, no cashback.
  4. Turn on a VPN on a fresh device: the cashback waits for a review.

Press Forget this device to start over.

Not a hard block

Families share a phone, so the second account still opens. Only the reward is held back, which removes the reason to farm.

The SDK collects device and browser metadata, never names, phone numbers or emails. The demo server keeps each device's history in memory for 24 hours, with mobile numbers masked.
