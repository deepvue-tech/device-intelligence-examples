Try to fool it

  1. Send an OTP.
  2. Press New number and send again. Then once more: the third number from one device is refused.
  3. Or keep resending to one number. The fourth request in 15 minutes is refused.
  4. Open a private window or clear this site's data. The limit still holds.
  5. Run it as a bot, for example in a headless browser. Bots get no SMS at all.
